# Dag 48: Udfyld en formular med Selenium

Dette projekt løser lektionen for dag 48 i Udemys "100 Days of Code: The Complete Python Pro Bootcamp". Lektionen viser, hvordan Selenium WebDriver arbejder med en side: klikke på elementer, skrive i felter, sende specialtaster og udfylde en formular.

## Hvad hvert trin giver dig

| Trin | Emne i lektionen | Funktion | Det lærer du |
| --- | --- | --- | --- |
| 1 | Klik på et link, find det via dets tekst | `click_link_by_text` | At navigere uden musen |
| 2 | Skriv i et felt og send Enter-tasten | `search_for` | At udfylde et felt og sende med en specialtast |
| 3 | Udfordring: udfyld en formular og klik på knappen | `fill_out_form` | At kombinere selektorer, indtastning og klik |

- [Trin 1: Klik på et link](Step-1-Link-Click-da)
- [Trin 2: Søg](Step-2-Search-da)
- [Trin 3: Formularen](Step-3-Form-da)

## Kør det

```bash
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m fill_out_form
```
